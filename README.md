# Web-dev-project-2

## Accessibility Improvements
Fixed an empty LinkedIn link by adding descriptive link text.
Updated navigation hover text to improve color contrast.
Adjusted text colors on the pink background to meet WCAG AA contrast requirements.
Tested text and background color combinations using WebAIM Contrast Checker.
Ran WAVE on all three pages and corrected the reported accessibility error.

## Gestalt Principles
Figure-Ground: Used a white project card with a border to distinguish project content from the page background.
Proximity: Adjusted spacing between project headings and descriptions to show that related content belongs together.

## Accessible Contact Form
- Added a contact form to the About page with Name, Email, and Message fields.
- Connected each form label to its input using matching for and id attributes.
- Added required attributes to prevent empty submissions.
- Used email input validation to check email formatting.
- Added accessible instructions using aria-describedby.
- Tested the form's required-field validation in the browser.
